# Projects and games

The same system works outside YouTube videos. The goal is still one
focal subject, one emotion, one stake, loud color, and almost no text.

## Sizes

| Placement | Size | Notes |
| --- | --- | --- |
| YouTube thumbnail | 1280x720 (16:9) | bottom-right corner is covered by the duration badge |
| Roblox experience thumbnail | 1920x1080 (16:9) | keep key art in the center; the icon (512x512) is a separate square |
| Steam main capsule | 1232x706 | the game logo is required on capsules; follow Steam's current capsule rules |
| Steam header capsule | 920x430 | logo plus key art; tiny in lists |
| itch.io cover | 630x500 | shown small in browse grids |
| App store screenshots | per store spec | first screenshot works like a thumbnail |
| Social post or launch image | 1600x900 or 1200x675 | same rules, add the product name |

Sizes change. Check the current specs before exporting:
[YouTube](https://support.google.com/youtube/answer/72431),
[Roblox](https://create.roblox.com/docs/production/publishing/thumbnails),
[Steam](https://partner.steamgames.com/doc/store/assets),
[itch.io](https://itch.io/docs/creators/design).

## Finding the hook in a project

| Project type | Where the stake hides | Example hook |
| --- | --- | --- |
| Game | the hardest boss, the biggest number, the rarest item, the strangest mechanic | "1 Player vs 1,000 Zombies" |
| Game devlog | time spent, money spent, players gained, what broke | "I Made A Game In 48 Hours" |
| App or tool | time saved, money saved, before vs after | "This App Saved Me 10 Hours" |
| Code project or repo | scale, speed, a bold comparison | "I Rebuilt X In 100 Lines" |
| Tutorial | the time promise or the result | "Pro Thumbnails In 10 Minutes" |

## Games without a face

- Use the main character, a mascot, or an enemy reacting with one exaggerated emotion. Zoom in hard.
- Or make the stakes object the hero: a giant boss, a mountain of loot, a huge damage number.
- Show the moment before the outcome: the ball an inch from the goal, the player at 1 HP.

## Store pages

- Game store capsules often require the logo; there, the logo plus one character plus one stake is the 3-element budget.
- Make the capsule match the first 5 seconds of the trailer and the first screenshot, so the promise is kept all the way down the page.
- Keep a consistent color and character across thumbnails, icons, and capsules so people recognize the project in a feed.
